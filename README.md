# Ciao, sono Davide Durazzi 👋

Di giorno lavoro tra le auto. Dalle 4 alle 7 del mattino costruisco un'**azienda con un solo umano**: io, e una squadra di agenti di intelligenza artificiale che scrivono, montano video, pubblicano e fanno i conti. Racconto tutto allo scoperto, anche quando i conti sono in rosso.
